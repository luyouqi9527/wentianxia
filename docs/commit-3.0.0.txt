feat(3.0.0): 升级 Flutter 3.47.5 + 液态玻璃改为 shader 真·背景折射

一、为什么升级
dart:ui 自 Flutter 3.29 起提供 ImageFilter.shader(FragmentShader)，且 BackdropFilter
接受它：引擎会把背景纹理绑到着色器第 0 个 sampler2D、把纹理尺寸写进第 0 个 vec2
uniform（这两个值禁止 Dart 侧设置）。于是着色器里 texture(uBackdrop, coord+位移)
可以**重采样真实背景像素** —— 这才是液态玻璃的定义性特征（边缘折射透镜）。
原基线 3.27.4 没有该 API（实测 painting.dart 只有 blur/dilate/erode/matrix/compose），
所以 1.x/2.x 只能用数学等价的解析式近似。3.29+ 同时提供 BackdropGroup 共享采样。

二、着色器（shaders/liquid_glass.frag）
与《液态玻璃实现技术文档》第 1 章、Kyant0 的 AGSL 实现逐条对应：
圆角矩形 SDF → 归一化深度 t=depth/refractHeight → circleMap（圆形倒角 + Snell 近似）
→ 法线 normalize(∇SDF)（梯度半径用 min(r×1.5, min(halfW,halfH)) 避开圆角放射状折痕）
→ sampleCoord = coord + grad × d → 重采样 → R/G/B 微差采样（色散）
→ abs(dot(grad, light)) 的 45° 双面边缘高光 → 内阴影 → 提饱和 → 中心压暗。
uniform 索引：0/1 = uSize（引擎写），2..10 = Dart 设置的玻璃参数。

三、三层降级（任何一层失败都不会崩、也不会跳变）
1. Impeller + 着色器加载成功 + 材质=液态玻璃 → ImageFilter.shader 真折射；
2. Skia / 加载失败 / isShaderFilterSupported=false → 解析式折射（_LiquidGlassPainter）；
3. 设置里选高斯模糊 → ImageFilter.blur(σ=10)。
真折射走**两层 BackdropFilter 叠加**（下层 blur、上层 shader），
刻意不用 ImageFilter.compose —— blur 与 shader 同 filter 在 3.38 前是坏的
（flutter#170820），叠两层是官方文档与 liquid_glass_renderer 的稳妥做法。
着色器在 main() 里只加载一次并覆盖 Provider，保证首帧即真折射。
